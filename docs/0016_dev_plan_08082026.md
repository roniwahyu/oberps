# DEV PLAN 0016: Rencana Pengembangan Lanjutan (Roadmap Next Steps)

**Tanggal**: 8 Agustus 2026  
**Status**: DRAF RENCANA MASA DEPAN  
**Target Rilis**: Phase 3.0 Oberps System

## 🎯 Rencana Roadmap Selanjutnya (Next Phase Roadmap)

### 1. Integrasi Sistem RBAC & Manajemen Pengguna (Role-Based Access Control)
- **Tujuan**: Memungkinkan login dosen, ketua program studi (Kaporprodi), dan unit penjaminan mutu (GPM/LPM).
- **Rencana Fitur**:
  - Dosen: Menyusun dan merevisi draf RPS.
  - Kaprodi: Meninjau (*review*), memberikan catatan masukan, dan menyetujui (*approve*) RPS.
  - LPM / Dekan: Mengunduh arsip RPS terverifikasi tingkat fakultas/universitas.

### 2. Peningkatan Ekspor Cetak PDF/HTML & Watermark Institusi
- **Tujuan**: Menghasilkan dokumen cetak resmi RPS dengan kop dan format tabel SN-DIKTI yang sempurna.
- **Rencana Fitur**:
  - Kustomisasi Logo Universitas & Program Studi pada header dokumen cetak.
  - Generator PDF client-side dengan penomoran halaman otomatis (*Page X of Y*).

### 3. Analitik Matriks Pembelajaran & Dashboard Evaluasi CPL
- **Tujuan**: Visualisasi peta ketercapaian CPL dan bobot CPMK antar mata kuliah dalam satu prodi.
- **Rencana Fitur**:
  - Diagram radar ketercapaian aspek (Pengetahuan, Keterampilan, Sikap).
  - Peta matriks kontribusi mata kuliah terhadap CPL lulusan prodi.

### 4. Automated Testing & Continuous Integration (CI/CD)
- **Tujuan**: Menjamin stabilitas kode jangka panjang dengan pengujian otomatis (Unit Test & E2E).
- **Rencana Fitur**:
  - Pengujian unit fungsi parser CoT dan KKO validator.
  - Pengujian end-to-end (Playwright/Cypress) untuk alur Wizard 9-step.
