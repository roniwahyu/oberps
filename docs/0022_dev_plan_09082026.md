## 🎯 Rencana Roadmap Selanjutnya (Next Phase Roadmap)

### 1. Integrasi Parser Impor 13-Sheet Excel Ke Database (`POST /api/curriculum/import`)
- **Tujuan**: Memungkinkan dosen/kaprodi mengunggah file `Implementasi_Modul_OBE*.xlsx` untuk secara otomatis disimpan ke tabel SQLite `CurriculumModule`.
- **Rencana Fitur**:
  - Auto-parsing 13 lembar sheet Excel menggunakan `xlsx`.
  - Simpan struktur PL, CPL, Peta I/R/M ke database SQLite.

### 2. Generator Visual Diagram Radar CPL Prodi (Recharts Component)
- **Tujuan**: Menampilkan diagram radar ketercapaian CPL prodi secara real-time pada UI dashboard.
- **Rencana Fitur**:
  - Komponen `CplRadarChart.tsx` mengonsumsi data `GET /api/curriculum/data`.

### 3. Agentic AI Automated Curriculum Optimizer Subagent
- **Tujuan**: Sub-agent AI otonom yang memeriksa ketimpangan CPL (misal CPL yang belum diukur pada level M) dan memberikan saran penambahan mata kuliah penciri prodi secara otomatis.
