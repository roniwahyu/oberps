## F. MATERI POKOK

1. Konsep dasar struktur data, Big-O notation, dan analisis kompleksitas algoritma.
2. Array: operasi dasar, array multidimensi, dan aplikasi.
3. Linked List: Single Linked List, Double Linked List, Circular Linked List.
4. Stack: implementasi Array-based dan Linked List-based, aplikasi ekspresi matematika (infix, prefix, postfix).
5. Queue: Linear Queue, Circular Queue, Deque, dan aplikasi antrean.
6. Hash Table: fungsi hash, collision resolution, dan aplikasi.
7. Rekursi: konsep dasar, divide and conquer, dan analisis kompleksitas rekursif.
8. Binary Tree dan Binary Search Tree: operasi CRUD dan traversal (inorder, preorder, postorder).
9. AVL Tree dan Heap Tree: self-balancing, priority queue, dan operasi heapify.
10. Graph: representasi adjacency list dan adjacency matrix, BFS dan DFS.
11. Algoritma Sorting: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort, Heap Sort.
12. Algoritma Searching: Linear Search, Binary Search, Hash-based Search.
13. Proyek terpadu: implementasi struktur data untuk studi kasus aplikasi nyata.
