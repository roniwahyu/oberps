## 📋 Rincian Tahapan Eksekusi

### Tahap 1: Penguatan Wizard UI 9-Step Interaktif
- **Step 1: Identitas Mata Kuliah** (Nama, Kode, SKS Teori/Praktikum, Semester, Prodi, Dosen).
- **Step 2: Unggah & Parse Acuan Kurikulum** (Dukungan XLSX `Implementasi_Modul_OBE*.xlsx`, PDF, CSV).
- **Step 3: Pemilihan & Penyelarasan CPL Dibebankan** (Seleksi CPL prodi otomatis dari file kurikulum).
- **Step 4: Formulasi CPMK (Prinsip ABCD)** (Rekomendasi otomatis KKO Anderson & Krathwohl terukur C3-C5).
- **Step 5: Matriks Taksonomi Bloom & Aspek Pembelajaran**.
- **Step 6: Scaffolding Rencana Mingguan M1 - M16** (Verifikasi otomatis bobot evaluasi = 100%).
- **Step 7: Perancangan Pembelajaran Berbasis Proyek (PjBL / Case Method)**.
- **Step 8: Formulasi Rubrik Penilaian Analitik 4x4**.
- **Step 9: Review Final, Generate LLM, & Ekspor**.

### Tahap 2: Parser Data Kurikulum Client-side (XLSX / CSV)
- Mengintegrasikan parser client-side (seperti `xlsx` / `sheetjs`) untuk membaca sheet `1. Profil Lulusan`, `2. CPL Prodi`, dan `4. CPL-MK` secara langsung di browser tanpa perlu server side processing.

### Tahap 3: Penyimpanan DB & Manajemen Modul Asset
- Memastikan integrasi dengan database SQLite (`db/custom.db`) untuk riwayat pembentukan RPS dan ekspor dokumen.
