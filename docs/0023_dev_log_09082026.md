## 📝 Rekapitulasi Pekerjaan Terakhir & Perbaikan Bug

### 1. Resolusi Console Error: Script Tag Warning (`src/components/theme-provider.tsx`)
- **File**: `src/components/theme-provider.tsx`
- **Akar Masalah**: Komponen `NextThemesProvider` (`next-themes`) merender tag `<script>` bawaan di dalam komponen React 19 tanpa atribut identifikasi khusus, sehingga memicu peringatan React 19 (*Encountered a script tag while rendering React component...*).
- **Solusi**: Mengisolasi dan meneruskan `scriptProps={{ "data-theme-script": "true" }}` pada `NextThemesProvider`, membebaskan *RootLayout* dari peringatan skrip.

### 2. Resolusi Recoverable Error: Hydration Mismatch (`src/components/rps/rps-builder.tsx`)
- **File**: `src/components/rps/rps-builder.tsx` (Baris 315)
- **Akar Masalah**: `useState` meng-evaluasi `loadStoredCurriculumContext()` secara langsung saat *initial state creation*.
  - Di **Server (SSR)**: `localStorage` bernilai `null` $\rightarrow$ `livePrompt` dirakit **tanpa** section `DOKUMEN ACUAN KURIKULUM PRODI TERLAMPIR...`.
  - Di **Client (Hydration)**: `localStorage` berisi data kurikulum $\rightarrow$ `livePrompt` dirakit **dengan** section acuan kurikulum.
  - Bentrokan HTML terjadi pada elemen `<pre>{livePrompt}</pre>`.
- **Solusi**: Menginisialisasi `curriculumContext` ke `null` pada render pertama (matching 100% antara Server & Client), kemudian memuat data `localStorage` di dalam hook `useEffect` setelah *mounting*.
