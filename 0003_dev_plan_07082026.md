# Development Plan & Roadmap — SmartRPS Builder OBE

**Tanggal**: 07 Agustus 2026  
**Format Berkas**: `0003_dev_plan_07082026.md`  
**Fokus Utama**: Optimalisasi Ekspor PDF, Batch Generation Kurikulum Prodi, & Fitur Kolaborasi

---

## 1. Tujuan Strategis Rencana Pengembangan

Rencana pengembangan ini disusun untuk memandu tahap pengembangan selanjutnya dalam meningkatkan fungsionalitas **SmartRPS Builder** dari generator per mata kuliah menjadi platform manajemen kurikulum OBE tingkat Program Studi yang komprehensif.

---

## 2. Rencana Fitur & Pembagian Tahap (Milestones)

### Phase 1: Optimalisasi Ekspor & Cetak PDF/Word (Target: Q3 2026)
- [ ] **Modul Cetak PDF Presisi SN-DIKTI**:
  - Menyempurnakan tata letak tabel RPS 16 minggu saat dicetak / diekspor ke PDF agar pas dengan kertas A4/F4 tanpa terpotong (*print stylesheet optimization*).
  - Menambahkan header resmi fakultas/universitas dan kolom tanda tangan pengesahan (Dosen Pengampu, Ketua Program Studi, Dekan).
- [ ] **Ekspor Format Word (.docx)**:
  - Menyediakan opsi ekspor langsung ke format Microsoft Word (`.docx`) agar dosen dapat melakukan penyuntingan narasi secara opsional sebelum pengesahan.

---

### Phase 2: Batch RPS Generator untuk Seluruh Mata Kuliah Prodi (Target: Q3-Q4 2026)
- [ ] **Batch Generation dari Excel Kurikulum**:
  - Mengizinkan pengguna memilih beberapa mata kuliah sekaligus dari file `Implementasi_Modul_OBE*.xlsx` yang diunggah.
  - Memproses pembuatan RPS secara paralel atau antrean (*queue processing*) untuk seluruh mata kuliah dalam satu semester/prodi.
- [ ] **Export/Import Massal**:
  - Fitur ekspor/impor seluruh RPS program studi dalam bentuk satu berkas arsip (`.zip` atau paket JSON).

---

### Phase 3: Analitik Ketercapaian CPL & Matriks Pemetaan Prodi (Target: Q4 2026)
- [ ] **Dashboard Analitik Kurikulum Prodi**:
  - Menampilkan grafik distribusi CPL di seluruh mata kuliah (CPL Sikap, Pengetahuan, Keterampilan Umum, Keterampilan Khusus).
  - Menilai apakah ada CPL yang *under-represented* (terlalu sedikit diukur) atau *over-represented* (terlalu banyak diukur).
- [ ] **Peta Level Pembelajaran (I / R / M)**:
  - Visualisasi interaktif level pemenuhan CPL per semester: *Introduced (I)*, *Reinforced (R)*, dan *Mastered (M)*.

---

### Phase 4: Integrasi LMS & Multi-Tenant / Kolaborasi Dosen (Target: Q1 2027)
- [ ] **Integrasi LMS (Moodle / Google Classroom)**:
  - Ekspor struktur RPS M1-M16 langsung menjadi modul/topik mingguan di Moodle atau Google Classroom.
- [ ] **Kolaborasi Team Teaching**:
  - Fitur penyuntingan RPS secara kolaboratif untuk tim dosen pengampu mata kuliah dengan penguncian sesi (*session locking*).

---

## 3. Catatan Implementasi & Standar Kualitas Codebase

1. **Prinsip Tanpa Deprekat**:
   - Selalu pertahankan kompatibilitas dengan SQLite native `node:sqlite` tanpa paket ORM berat.
2. **Keamanan API Key**:
   - Token API LLM tetap disimpan di peramban pengguna (`localStorage`) dan tidak pernah disimpan secara permanen di database server.
3. **Kepatuhan Pedoman SN-DIKTI**:
   - Setiap pembaruan prompt wajib mematuhi aturan Kata Kerja Operasional (KKO) revisi Anderson & Krathwohl serta format ABCD.
