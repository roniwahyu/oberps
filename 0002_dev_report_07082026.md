## 1. Pendahuluan & Latar Belakang

Aplikasi **SmartRPS Builder** dirancang untuk membantu dosen dan penyusun kurikulum perguruan tinggi merumuskan Rencana Pembelajaran Semester (RPS) berstandar **Outcome-Based Education (OBE)** sesuai dengan standar **SN-DIKTI Indonesia**.

Pengembangan tahap ini berfokus pada:
1. **Kemandirian Aplikasi**: Menghapus ketergantungan pada framework Z-AI (`z.ai`) dan paket ORM Prisma.
2. **Basis Data SQLite Native**: Menggunakan modul `node:sqlite` bawaan Node.js 24 untuk kemudahan portabilitas dan tanpa dependensi eksternal.
3. **Pengaturan API Key LLM Multi-Provider**: Halaman khusus pengaturan token API untuk OpenAI, Anthropic Claude, OpenRouter, Dahl Global (Kimi), dan Custom Local Endpoint.
4. **Penerapan Master Prompt SN-DIKTI**: Penyelarasan prompt generator berdasarkan pedoman 18-step dari dokumen PDF master (`PROMPT - BUAT RPS OBE With AI (1).pdf`).
5. **Dukungan Dokumen Kurikulum Institusi**: Pembacaan berkas Excel kurikulum (`Implementasi_Modul_OBE*.xlsx`) untuk integrasi data CPL, Profil Lulusan (PL), dan peta CPMK.

## 3. Detail Implementasi Modul Utama

### A. SQLite Native DB Layer (`src/lib/db.ts`)
- Menggunakan `DatabaseSync` dari `node:sqlite` (Node.js v24.13.1).
- Mode WAL (*Write-Ahead Logging*) dan `busy_timeout = 5000` mencegah *file lock contention* selama kompilasi multi-worker Turbopack Next.js.
- Menyediakan metode CRUD: `getAllRPS()`, `getRPSById()`, `createRPS()`, `updateRPS()`, `deleteRPS()`, `duplicateRPS()`, `getStats()`, `batchDeleteRPS()`.

### B. Multi-Provider LLM Integration (`src/app/api/rps/generate/route.ts`)
- **OpenAI API**: Format Payload `/v1/chat/completions`, Header `Authorization: Bearer <KEY>`.
- **Anthropic Claude API**: Format Payload `/v1/messages`, Header `x-api-key: <KEY>`, `anthropic-version: 2023-06-01`.
- **OpenRouter**: Endpoint `https://openrouter.ai/api/v1/chat/completions`.
- **Dahl Global**: Endpoint `https://inference.dahl.global/v1/chat/completions` dengan dukungan multi-model (`moonshotai/Kimi-K2.6`, `moonshotai/Kimi-K1.5`).
- **Offline Fallback**: Engine internal `generateFallbackRPS()` jika tidak ada API key atau dalam Mode Mandiri.

### C. Pembaca Acuan Kurikulum Excel (`src/components/rps/curriculum-uploader.tsx`)
- Membaca berkas `.xlsx` secara langsung di sisi peramban menggunakan pustaka `xlsx`.
- Mengekstrak CPL, Profil Lulusan (PL), dan pemetaan CPMK.
- Menyimpan hasil ekstraksi di `localStorage` dan menyuntikkannya ke dalam prompt LLM.
