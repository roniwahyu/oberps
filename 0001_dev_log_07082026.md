### 2. Penggantian Prisma dengan Native SQLite (`node:sqlite`)
- **Migrasi Basis Data**: Menghapus `@prisma/client`, paket `prisma`, dan folder `prisma/`.
- **Modul DB Native**: Membuat `src/lib/db.ts` memanfaatkan `DatabaseSync` bawaan Node 24 targeting `db/custom.db`.
- **Penanganan Concurrency**: Mengaktifkan `PRAGMA journal_mode = WAL;` dan `PRAGMA busy_timeout = 5000;` untuk mencegah kesalahan `SQLITE_BUSY: database is locked` saat Turbopack mengumpulkan data halaman dengan multi-worker.
- **Dynamic Routes**: Menambahkan `export const dynamic = "force-dynamic";` pada semua API route handler (`/api/rps`, `/api/rps/[id]`, `/api/rps/stats`, dll).
